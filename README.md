# تطبيق عائلة آل سلوم (نسخة تجريبية)

نسخة تجريبية من تطبيق العائلة: دردشة بين أفراد العائلة، ومناسبات وتأكيد حضور، وإشعارات على الجوال.

- الأسماء والرسائل الموجودة فيها أمثلة للتجربة، ولا يُرسل منها شيء لأحد.
- كل ما يكتبه المجرّب يبقى على جواله فقط.
- تُفتح من الجوال، ويمكن تثبيتها على الشاشة الرئيسية لتصل إشعاراتها.
